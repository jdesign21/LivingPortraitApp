Information & Privacy

When enabled, LivingPortraitApp sends a limited set of events to PostHog (US Cloud) to help understand installation activity, supported environments, and application reliability.

Information that may be collected
  • Application launch events.
  • LivingPortraitApp version, operating system, OS release, CPU architecture, and Python version.
  • A randomly generated installation identifier that is not based on your name or administrator account.
  • Application errors with a short, sanitized error type and message when available.
  • Your optional diagnostic contact email only with diagnostic error events.
Information that is not collected
  • No page-view tracking or browsing history.
  • No video files, images, recordings, filenames, playlists, or personal media.
  • No administrator username, password, account details, hardware serial number, hostname, or local IP address.
  • No full error stack traces, memory dumps, or application logs.
Network and privacy

Analytics is sent to PostHog over HTTPS. PostHog necessarily receives network connection information to process the request. GeoIP enrichment is disabled in event properties. No analytics events are sent unless you opt in.

You can disable analytics at any time. Disabling it stops new events and removes the optional diagnostic contact email stored by LivingPortraitApp.

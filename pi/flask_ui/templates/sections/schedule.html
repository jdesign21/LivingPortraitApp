Playback Schedule

Set specific playback times for each day. Enable a time slot and choose its start and end time. You can also select a video tag to limit playback to videos with that tag. If no video tag is selected, all active videos will play during that time period.

If a day has no enabled time slots, playback will run all day using the normal playback settings.

Wiring Guide
  • HDMI from Pi to TV:
    HDMI cable runs from the Raspberry Pi’s HDMI port to the TV.
  • PIR Sensor Wiring:
    • VCC (Red) → 5V pin on Pi
    • GND (Black) → GND pin on Pi
    • OUT (Yellow) → GPIO pin on Pi (GPIO 4)
  • 5V Power Supply:
    Properly connected to the Pi’s micro-USB port.

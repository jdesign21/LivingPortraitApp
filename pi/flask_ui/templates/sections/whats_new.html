What's New

LivingPortraitApp v2.0.0 Stable Release

Version 2.0.0 is a major update that adds Primary/Secondary synchronization, expanded playback controls, audio configuration, dynamic scheduling, application updates, and a redesigned interface.

Playback & Synchronization
  • Added Primary/Secondary video synchronization.
  • Added configurable Secondary start modes and delays.
  • Added Secondary Video Selection options.
  • Added Trigger Change for Primary and Secondary playback.
  • Improved playlist switching and synchronized playback.
Audio
  • Added automatic audio device detection.
  • Added configurable audio output for Primary, Secondary, and individual videos.
  • Added per-screen audio mute settings.
Scheduling
  • Added 12-hour and 24-hour time format support.
  • Added dynamic Schedule Tags.
  • Added Schedule Tag management to the Videos section.
Network & MQTT
  • Added MQTT connection status and automatic reconnect handling.
  • Improved Primary/Secondary network communication and synchronization.
  • Improved Secondary Pi monitoring and system status.
  • Improved network settings and status messages.
Application Updates
  • Added application update management to the web interface.
  • Added Stable and Beta release checking.
  • Added Update Now and update progress tracking.
  • Added automatic application restart after updates.
  • Added protection for user settings and videos during updates.
Dashboard & Setup
  • Added a first-run setup page.
  • Redesigned the dashboard and user interface.
  • Improved Primary and Secondary Pi setup.
  • Improved video and Sync Tag management.
  • Improved system status information.
System & Installer
  • Added automatic application startup and version tracking.
  • Added automatic log cleanup after 30 days.
  • Improved the Raspberry Pi installation and setup process.
  • Installer now automatically configures required dependencies, MQTT, the Python environment, and system services.
Stability

Fixed numerous playback, synchronization, networking, playlist, and application update issues discovered during beta testing.
